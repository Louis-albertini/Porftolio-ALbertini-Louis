Crystal Cave

Category
Environment
Role

Date
2025–2026

This cave is part of my final school project, for which I was responsible for creating all the static props. This scene was our little playground, as it was created during pre-production to test myself and explore different possibilities. The lighting was done in Unreal Engine alongside Mathias Cocherel, another student. The biggest challenge for this piece was creating a small set of rocks that could be combined to build an interesting environment.
