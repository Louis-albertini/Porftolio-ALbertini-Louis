building design with only one texture and few assets. These assets are part of my final school project. Since we needed to create buildings that would fit into the jungle environment, we needed a way to give them different shapes and sizes without having to create too many individual assets, which would have been time-consuming and could have caused performance issues. So, I created a modular building system using the same logic as a trim sheet. This allowed us to iterate on our building designs much more easily, using only one texture and a few assets.
